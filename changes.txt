Version 18.0.0 (2026-11-09)
- New version scheme: MAJOR.MINOR.PATCH, independent of game version.
  Supported game versions are listed in the TOC's Interface line instead.
- Single TOC supporting all current game versions:
  Retail (120100, 120105), Classic (50504, 38000, 38002, 20506),
  Classic Era (11508, 11509), WoW: Forever (16001)
- Uses C_Item.GetItemInfo and TooltipDataProcessor when available,
  with fallbacks for older clients
- Fixed error when hovering items not yet in the item cache
